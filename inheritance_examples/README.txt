Java Inheritance Examples
=========================
This zip contains multiple small Java projects demonstrating different inheritance types:
- animal_hierarchy: abstract superclass Animal with Dog, Cat, Bird. Demonstrates constructors, overriding, polymorphism.
- employee_management: Employee superclass and Manager/Developer/Intern subclasses.
- vehicle_transport: Vehicle superclass and Car/Truck/Motorcycle subclasses.
- single_inheritance: Book->Author example.
- smart_home: Device->Thermostat example.
- multilevel_inheritance: Order->ShippedOrder->DeliveredOrder.
- course_hierarchy: Course->OnlineCourse->PaidOnlineCourse.
- hierarchical_inheritance: BankAccount with Savings/Checking/FixedDeposit.
- school_system: Person with Teacher/Student/Staff.
- hybrid_restaurant: Person + Worker interface implemented by Chef and Waiter.
- hybrid_vehicle: Vehicle with PetrolVehicle implementing Refuelable and ElectricVehicle featuring charge().

How to compile & run (from each project folder):
  javac *.java
  java Main
(Some classes may require Java 8+ for java.time APIs)

Best practices file included.
